Định dạng dữ liệu

Vì sao tạo thanh toán bằng query string trên URL

VNPAY yêu cầu
Kênh 1 là chuyển trang. Payment Service tạo link, trình duyệt mở link. Dữ liệu đi theo link nên nằm trên query string, phương thức GET
VNPAY yêu cầu
Khách nhập thẻ trên trang VNPAY. Payment Service không nhận số thẻ nên không phải đạt chuẩn PCI-DSS
VNPAY yêu cầu
URL không chứa được dấu cách, &, =, :, / trong giá trị, nên phải URL-encode
Mình chọn
Payment Service trả JSON {txnRef, paymentUrl} thay vì tự chuyển trang, để web quyết định cách hiển thị
// trước khi encode: dấu cách, ":" và "/" làm hỏng cấu trúc URLvnp_OrderInfo=Thanh toan Ca phe&vnp_ReturnUrl=http://localhost:8080/vnpay/return// sau khi encodevnp_OrderInfo=Thanh+toan+Ca+phe&vnp_ReturnUrl=http%3A%2F%2Flocalhost%3A8080%2Fvnpay%2Freturn
