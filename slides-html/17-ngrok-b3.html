ngrok · bước 3

Gắn authtoken, bước hay quên nhất

1
Mở dashboard.ngrok.com/get-started/your-authtoken
2
Ở khung Command line, bấm icon copy bên phải. Nó copy kèm token thật
3
Dán vào terminal, Enter
ngrok config add-authtoken 2abc...XyZ

# kiểm tra
ngrok config check
Valid configuration file at /Users/ban/Library/.../ngrok.yml

Báo no such file nghĩa là chưa gắn được, làm lại bước 2.
