Phần 3 – ngrok

Bước 3: Thêm authtoken

  • Vào dashboard.ngrok.com/get-started/your-authtoken
  • Ở mục Command line, bấm nút copy (có sẵn token của mình)
  • Dán vào terminal rồi Enter
ngrok config add-authtoken 2abc...XyZ # kiểm tra lạingrok config checkValid configuration file at .../ngrok.yml

Nếu báo no such file là chưa thêm được, làm lại bước 2.
