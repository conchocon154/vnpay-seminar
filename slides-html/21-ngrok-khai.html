Mở endpoint ra internet

Khai URL trên VNPAY rồi chạy lại Java

Vào sandbox.vnpayment.vn/merchantv2 → Cấu hình → Thông tin website

MụcĐiền
URL trả vềhttps://<id>.ngrok-free.app/vnpay/return
URL nhận kết quả IPNhttps://<id>.ngrok-free.app/vnpay/ipn
Terminal 2 – macOS, Linux
export VNPAY_RETURN_URL=https://<id>.ngrok-free.app/vnpay/returnjava ShopStart.java
Terminal 2 – Windows PowerShell
$env:VNPAY_RETURN_URL="https://<id>.ngrok-free.app/vnpay/return"java ShopStart.java
