Bước 2: Cài ngrok

macOS
brew install --cask ngrok
Linux
sudo snap install ngrok
Kiểm tra
ngrok versionngrok version 3.x.x
Windows
  • Tải file zip ở ngrok.com/download
  • Giải nén ra file ngrok.exe
  • Bỏ vào chung thư mục với ShopStart.java
.\ngrok.exe version
