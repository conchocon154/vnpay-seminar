Tổng kết

Tóm tắt

  • Payment Service là service duy nhất giao tiếp với VNPAY
  • Bốn kênh: link thanh toán (GET), ReturnURL (GET), IPN (GET, webhook), querydr (POST JSON)
  • Tham số, định dạng, cách ký và mã phản hồi do VNPAY quy định
  • Query string vì kênh 1, 2 là chuyển trang. JSON vì querydr là server gọi server
  • Chỉ IPN và querydr được cập nhật trạng thái đơn
  • Lưu đơn, khoá, secret, event là phần mình thiết kế theo hệ thống
