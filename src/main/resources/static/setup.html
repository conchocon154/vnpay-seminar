Trang này chỉ dành cho sandbox. Nó ghi đè credential lúc đang chạy, nên server chỉ chấp nhận request gõ thẳng vào localhost — mở qua link ngrok sẽ bị từ chối. Lên production thì xoá SetupController và nạp secret từ Vault / K8s Secret.
